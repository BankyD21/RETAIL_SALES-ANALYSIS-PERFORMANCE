# 📊 Retail Sales Performance Analysis

An Excel-based analysis of retail sales data, built to uncover sales trends, top-performing products and categories, and key drivers of business performance.

---

## 📌 Project Overview

This project analyses retail sales data to answer practical business questions such as:

- How are total sales, profit and quantity sold performing over time?
- Which products and categories generate the most revenue?
- Which regions, stores or customer segments perform best?
- Are there seasonal or monthly patterns in sales?

> **Goal:** Turn raw sales data into clear, decision-ready insights that a business can act on.

## 🛠️ Tools & Skills Used

- **Microsoft Excel**
  - Data cleaning and formatting
  - Formulas and functions (SUMIFS, COUNTIFS, AVERAGEIFS, IF, XLOOKUP/VLOOKUP)
  - Pivot Tables and Pivot Charts
  - Charts and dashboard design
  - Slicers for interactive filtering

---

## 🔍 Methodology

1. **Data Collection:** Imported the retail sales dataset into Excel.
2. **Data Cleaning:** Removed duplicates, handled missing values, fixed data types and standardised column names.
3. **Data Preparation:** Created calculated columns (e.g. Month, Year, Total Sales, Profit Margin).
4. **Analysis:** Built pivot tables to summarise sales by product, category, region, customer segment and time period.
5. **Visualisation:** Created charts and a summary dashboard to present the findings.

---

## 📈 Key Metrics (KPIs)

- Total Sales / Revenue
- Total Profit
- Total Quantity Sold
- Average Order Value
- Profit Margin (%)
- Sales Growth (month-over-month / year-over-year)
